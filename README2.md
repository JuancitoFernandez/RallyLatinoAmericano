# Rally — Monorepo

Stack: **React Native** | **React Desktop** | **NestJS**

## Apps
- **desktop** — Botonera (🟢 Medicina / 🔵 Policía / 🔴 Bombero) + 3 paneles
- **mobile**  — React Native con las mismas 3 secciones
- **backend** — NestJS API con módulos por servicio

## Comandos
```bash
npm run dev:desktop
npm run dev:mobile
npm run dev:backend
```
